# NguyênTôn English Icons

Icon set for the English vocabulary learning website.

## GitHub Pages
Upload the entire contents of this folder to your repository root.

Then add the contents of `html-head.html` inside `<head>` of your HTML page.

## Included
- favicon.ico
- site.webmanifest
- icons from 16x16 through 512x512
- Apple touch icon: 180x180
- PWA manifest icons: 192x192 and 512x512
